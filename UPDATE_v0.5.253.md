# Solo Anime Studio v0.5.253

- Brush hover now shows the tip silhouette, including chalk, bristles, procedural Nature stamps, and imported bitmap masks. Round tips and the round erasers use a circle.
- The outline follows zoom, rotation, and supported brush tip controls. A dashed guide shows the scatter area. Small and large outlines include a centre crosshair.
- **Full Brush Settings → Cursor** offers **Tip outline**, **Circle**, **Crosshair**, **Tip outline + crosshair**, and **Dot**. The selected style applies across brushes and erasers. The existing per-brush cursor visibility setting is still available.
- Cursor outlines are cached by tip and screen-size bucket. Hover updates run on the cursor overlay and leave saved stroke and project data intact.

This ZIP contains the full changed and new files for the v0.5.252 source tree. Extract it over that tree and keep the folder structure.
