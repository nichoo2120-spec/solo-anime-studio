# Solo Anime Studio 0.5.202

Brush Settings now opens a closable panel from the brush controls. Preset, size and opacity remain accessible in the compact brush area.

The panel organizes existing controls into Stroke width, Smoothing, Taper, Pen pressure, Tip & texture, Paint & mixing, and Advanced. A live preview reflects the current brush, and presets can be saved or reset inside the panel. Brush-specific controls appear when applicable; each brush keeps its own settings.

Opening the panel overlays the workspace without resizing the drawing canvas. Close with Done, the close button, or Escape while using the panel. Responsive layout keeps controls within smaller windows.

This is the brush settings organization update. The proposed editable width-profile graph and width-point editing of existing strokes are not included in this release. Automatic width variation remains available for Studio Ink and Contour Flow; existing pressure thickness limits are available for all brushes.

Validation covers categorized controls, unchanged canvas bounds, independent settings, custom save/reset, keyboard closing and focus return, compact layout, and the full existing drawing, paint and Windows update checks.
