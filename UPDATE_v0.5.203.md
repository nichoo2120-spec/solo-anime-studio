# Solo Anime Studio 0.5.203

Tip & texture now has adjustable round/oval tips, roundness, angle, follow-direction, texture strength and grain scale for Studio Ink, Contour Flow, Technical Pen, G-Pen, Mapping Pen and Brush Pen. Custom ink controls are disabled in Mix mode, whose paint nib remains separate. Dry bristle brushes expose paper-grain size and strength; paint brushes retain their existing material-specific controls. Fixed pencil/eraser tips explain their limits.

Changes apply to new strokes. Existing saved artwork and unedited brush defaults retain their renderers. Edited presets save and restore their custom tip settings; saved edited strokes reopen with the same appearance. New custom ink captures use stable live refinement.

Validation: pixel changes for shape/roundness/angle/direction/grain across all six supported ink brushes, native/display parity, saved project replay and validation, preset restoration, UI persistence, and existing desktop checks. Local simulated pen checks additionally verify settled ink, pen-up and reopen stability. The advanced width-point editor is separate pending work, not included in this update.
