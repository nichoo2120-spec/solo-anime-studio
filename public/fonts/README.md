# Existing Studio fonts, served locally

DM Sans and Manrope are the font families already requested by Studio’s stylesheet. The original variable TrueType files are bundled here so launching Studio does not depend on Google Fonts connectivity. No font outlines were modified.

Source: the official google/fonts repository, ofl/dmsans and ofl/manrope. Full source URLs, Git blob IDs and SHA-256 values are in validation/v148-font-assets.json. Both original OFL license files are included here.
